# 0005. Репозиторий на GitHub создаётся приватным

## Контекст

Пользователь написал «можешь закинуть на гитхаб» (G02) и не назвал видимость. В репозитории лежат материалы клиента: вайрфрейм, обложка канала, шаблон коэффициентов, тексты брифа.

## Решение

Репозиторий создаётся приватным. Код заливается туда, ссылка идёт в финальный отчёт. Открыть репозиторий можно одной командой, когда пользователь это скажет.

## Почему

- Публичный репозиторий: публикация чужих материалов необратима, потому что копии, форки и кэши остаются после закрытия. Видимость не названа, значит такого разрешения нет.
- Спросить пользователя перед созданием: сборка идёт без диалога, а приватный репозиторий выполняет просьбу целиком, ничего не теряя.

## Последствия

- Клиент и все, кому нужен доступ, должны быть приглашены явно. Ссылка из отчёта по умолчанию им не откроется.
- Бесплатные сервисы публикации, которым нужен публичный репозиторий, пока недоступны.
- Решение одностороннее в безопасную сторону: приватный можно открыть, обратно закрытое уже не вернуть. Поэтому его не нужно пересматривать при следующей сборке, пока пользователь сам не скажет иначе.
