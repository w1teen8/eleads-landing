# 0004. Карта GEO рисуется на одном canvas без картографических библиотек

## Контекст

Бриф просит точечную карту мира с пульсирующими точками, hover и tap по региону, лёгкую, без картографических библиотек, и не больше одного canvas на странице с паузой вне экрана.

## Решение

Карта — единственный `<canvas>` на странице. Сетка суши (шаг 2.5°) и координаты регионов хранятся в JSON, проекция — эквидистантная цилиндрическая, пульсация — синус по времени. Цикл ставится на паузу через `IntersectionObserver`. Суша кэшируется вне DOM и показывается как фон того же canvas. Список регионов справа — полноценная альтернатива карте.

## Почему

- Подключить картографическую библиотеку (d3-geo, Leaflet, Mapbox): прямо запрещено брифом, тянет сотни килобайт и мешает цели Lighthouse 85+.
- SVG с точками-элементами: сотни узлов и анимация пульса на каждом нагружают слабый Android, а canvas рисует всё одним проходом.
- WebGL в духе activetheory.net: бриф просит «вау» без тяжёлых шейдеров.
- Реальная картографическая проекция (Меркатор): для декоративной карты не нужна, а с цилиндрической проще расставлять точки по широте и долготе.

## Последствия

- Контуры суши грубые: сетка 2.5° не передаёт острова и береговую линию. Для макета принято, для финала может не хватить.
- Точки привязаны к сетке, поэтому новый регион добавляется правкой JSON, но выглядит правдоподобно только при правильных координатах.
- Лимит «один canvas» становится правилом проекта: любой следующий canvas-эффект придётся делать иначе.
- На момент решения карта, закрепление секции «Процес» и раскладка не проверялись в браузере, только чтением и сборкой. Это надо закрыть до показа клиенту.
- Tap по точке на телефоне может промахиваться по мелкой цели, поэтому список справа не декор, а обязательный запасной путь.
