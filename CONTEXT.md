# eLeads

Лендинг эксперта по Telegram Ads Володимира Кучера (бренд eLeads): рекламные кампании для бизнесов и экспертов, страница заканчивается переходом в личный Telegram.

## Язык

**Кейс**:
Один выполненный проект клиента с бюджетом, результатом и CPA/CPS. Всего семь, первый показывается крупнее.
_Избегать_: проект, история успеха, портфолио

**Ніша**:
Сфера бизнеса клиента, под которую считается прогноз и подбираются примеры. В калькуляторе их четыре, в сетке на странице восемь.
_Избегать_: вертикаль, индустрия, сегмент

**GEO**:
Страна или регион, где показывается реклама. В калькуляторе два: Україна и Worldwide, на карте семь регионов.
_Избегать_: локация, страна, таргет

**Eyebrow**:
Короткая метка над заголовком секции, например «02 / МАСШТАБ КАНАЛУ». Номер сквозной по порядку секций, слова клиентские.
_Избегать_: надзаголовок секции, лейбл

**Надзаголовок**:
Строка над заголовком первого экрана «TELEGRAM PERFORMANCE MARKETING». Это отдельный текст из брифа, не eyebrow секции.
_Избегать_: подзаголовок, тег

**Заглушка «уточнити»**:
Видимая пометка на месте данных, которых клиент ещё не дал: цифры кейсов, отзывы, ответы FAQ. Заменяет выдуманное правдоподобное значение. В английском тексте — «TBD».
_Избегать_: плейсхолдер, lorem, пустое поле

**Демо-коэффициенты**:
Временные значения CPM, CTR и CR в калькуляторе, пока клиент не прислал свои. Прогноз с ними нельзя считать фактом, об этом предупреждает плашка.
_Избегать_: тестовые данные, примерные цифры

**Пре-рендер**:
Вписывание украинского текста из JSON в готовый HTML при сборке, чтобы страница читалась без скрипта.
_Избегать_: SSR, серверный рендер, генерация

**Ступень воронки**:
Один из трёх уровней прогноза: Покази, Кліки, Підписники (или Ліди, Користувачі). Ширина ступени показывает масштаб числа.
_Избегать_: этап воронки, шаг воронки

**CPA/CPS**:
Цена за целевое действие: заявку (CPA) или подписчика (CPS). В кейсах и прогнозе показывается крупно, это главное число для клиента.
_Избегать_: CPL, стоимость лида, цена клика

**Ревил**:
Появление блока при прокрутке: проявление и сдвиг снизу, один раз. При «уменьшить движение» отключается, блок просто виден.
_Избегать_: fade-in, анимация входа

**Макет**:
Текущий этап проекта: четыре блока (шапка, первый экран, калькулятор, кейсы) доведены до финала, остальные десять собраны каркасом с настоящим текстом.
_Избегать_: прототип, MVP, черновик

**Каркас**:
Секция с финальной раскладкой и настоящим текстом, но без доводки и без материалов клиента.
_Избегать_: заготовка, скелет
