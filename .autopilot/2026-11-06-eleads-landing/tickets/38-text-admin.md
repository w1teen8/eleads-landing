## Что должно заработать

Страница `/admin/` (в продакшене — `https://w1teen8.github.io/eleads-landing/admin/`): владелец сайта меняет **весь текст страницы**
и сохраняет — через ~2 минуты сайт пересобирается GitHub Actions с новыми текстами.

- **Что редактируется:** `src/data/content.ua.json` + `content.en.json` (все строки, рядом UA и EN одной строкой формы),
  `src/data/faq.json` (вопросы и ответы UA/EN), `src/data/cases.json` (текстовые поля кейсов UA/EN: имя, ниша, бюджет, результат,
  CPA, задача, GEO, отзыв…), `src/data/config.json` → `telegramUrl`, `telegramHandle`. Не редактируются: ключи, структура, числа
  калькулятора, флаги (`avatar`, `accent` и т. п.) — только строковые значения.
- **Раскладка:** слева список разделов по экранам сайта в порядке страницы (Перший екран, Telegram у цифрах, Ніші, …, Підвал) —
  человекочитаемые названия (`nav.sections.*` и т. п.), не ключи; справа поля раздела: подпись (путь ключа мелко), поле UA, поле EN
  (`textarea` с автовысотой для длинных). Поиск по всем текстам. Изменённые поля подсвечены, счётчик «Змінено: N», «Скасувати
  зміни». Пустое значение не даёт сохранить (сборка упала бы). Предпросмотр — ссылка «Відкрити сайт».
- **Вход:** поле «GitHub token» (fine-grained, доступ только к репозиторию `w1teen8/eleads-landing`, право Contents: Read and write —
  в README пошаговая инструкция со ссылкой на https://github.com/settings/personal-access-tokens/new). Токен хранится в
  `sessionStorage`, галочка «Запам’ятати на цьому пристрої» — `localStorage`; кнопка «Вийти» стирает. Токен уходит **только** на
  `https://api.github.com`. Проверка при входе: `GET /repos/{owner}/{repo}` → права push; иначе понятная ошибка.
- **Сохранение:** для каждого изменённого файла `GET /repos/{owner}/{repo}/contents/{path}?ref=main` (sha) → `PUT` с новым
  содержимым (base64 UTF-8, форматирование JSON как в репозитории: 2 пробела, перевод строки в конце), сообщение коммита
  «Тексти: правка через адмінку (N полів)». Несколько файлов — одним коммитом через Git Data API (tree + commit + ref), чтобы не было
  нескольких деплоев. Если файл на сервере изменился с момента загрузки (sha другой) — не перезаписывать, предложить
  «Оновити й повторити». После сохранения — ссылка на запуск Actions и сообщение «Сайт оновиться за 2–3 хвилини».
- **Откуда берутся тексты:** при входе админка читает файлы через API из `main` (актуальная версия, а не вшитая в сборку).
- **Владелец/репозиторий/ветка** — константы в `src/admin/config.js` (`w1teen8`, `eleads-landing`, `main`).

## Безопасность

- Сайт вставляет тексты как текст (пре-рендер экранирует, клиент — `textContent`) — проверить, что ни один путь вывода текстов не
  использует `innerHTML`; если найдётся — исправить на текст. В админке значения тоже только через `value`/`textContent`.
- `admin.html`: `<meta name="robots" content="noindex,nofollow">`, на сайт не ссылается, в `sitemap` не попадает. CSP-мета:
  `connect-src https://api.github.com` + свой origin.
- Ни токен, ни email пользователя не пишутся в код, логи, коммиты.
- Ограничение длины поля (например 2000 символов) и запрет управляющих символов.

## Критерии приёмки

- [ ] `npm run build` собирает две страницы: `dist/index.html` и `dist/admin/index.html` (или `dist/admin.html` + доступ по `/admin/`), с `BASE_PATH=/eleads-landing/` — пути верные
- [ ] Логика без сети покрыта тестами: разбор JSON в список полей (только строки, пути), обратная сборка JSON с правками без потери структуры и порядка ключей, формат вывода как в репо, валидация (пусто, длина), base64 UTF-8 с кириллицей, группировка по разделам
- [ ] В браузере проверено с подменой `api.github.com` (перехват запросов в puppeteer): вход, правка двух полей в двух файлах, один коммит (tree/commit/ref), конфликт sha → предложение обновить; токен не уходит ни на какой другой хост
- [ ] Интерфейс в стиле сайта (палитра, шрифт канала в заголовках), удобен на 1366+ и терпим на телефоне
- [ ] Блок в README «Як змінювати тексти»: создать токен (шаги), открыть /admin/, сохранить, ждать деплой
- [ ] `npm run check` и `MSYS_NO_PATHCONV=1 BASE_PATH=/eleads-landing/ npm run check` — зелёные
- [ ] В возврате — скриншоты: вход, раздел с полями, поиск, состояние «Змінено: 2», успешное сохранение (на подменённом API)
