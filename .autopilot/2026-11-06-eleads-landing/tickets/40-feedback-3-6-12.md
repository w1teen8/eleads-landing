## Что сделать

**Блок 3:** плитка «SaaS / B2B» → «SaaS» (UA и EN).

**Блок 6 «Кейси»:** у Trackdesk и Finmap ниша «SaaS / B2B». **Линию роста убрать** («графік без змістовного пояснення»). Карточка: лого/аватар, назва клієнта та ніша (как сейчас), **GEO**, **ціль кампанії**, **3 ключові показники** (подпись + значение крупно, акцент цвета клиента). В `cases.json` у кейса: `geo {ua,en}`, `goal {ua,en}`, `metrics: [{label{ua,en}, value{ua,en}} ×3]` — значения «уточнити» / «TBD», пока клиент не пришлёт («ЗІБРАТИ ПОКАЗНИКИ»); подписи показателей по умолчанию: «Бюджет», «Результат», «CPA / CPS». Модалка кейса показывает те же поля + «детальна інформація» (`task`, `done`, `review` — как сейчас). Лента по прокрутке остаётся.

**Блок 12 «Матеріали»:** карточки: **зображення поста** (слот `<img>` из `materials.items.*.image`, путь в `public/img/posts/…`; пока нет — нынешняя обложка-заглушка), **назва** (title), **опис** 1–3 речення (`materials.items.*.text`, «уточнити»), **джерело** — фото и название канала «єЛіди! → [маркетинг]» (`materials.channel` = «єЛіди! → [маркетинг]», фото канала `materials.channelImage`, пока нет — круг-заглушка), кнопка «Читати в Telegram» → `materials.items.*.url` (пока нет — `config.telegramUrl`). Поля url/image должны редактироваться в админке (строки в словаре).

## Общие условия

- Источник — документ клиента: `reference/client-feedback/page-*.png` и дословные цитаты в брифе 3 («Дополнения», 2026-11-11). Не выдумывать данных: где нет цифр/картинок/ссылок — видимая заглушка «уточнити», поле в данных, чтобы клиент заполнил через админку `/admin/`.
- Облик блоков, выбранный пользователем, сохраняется; меняется только то, что сказано в документе. Тексты — только из `content.*.json` (новые ключи — в оба словаря; админка подхватывает их автоматически — проверь `tests/admin-*`).
- Один экран на 1903×937, 1920×1080, 1366×768 (UA и EN); 390×844 — без горизонтального скролла. Только `transform`/`opacity`; reduced-motion и `?nomotion=1` — статично.
- Параллельно работают другие исполнители: в `index.html` и словарях — только свои секции, точечно через Edit с перечитыванием файла.
- `npm run check` и `MSYS_NO_PATHCONV=1 BASE_PATH=/eleads-landing/ npm run check` — зелёные. В возврате — скриншоты 1903×937 и 390×844 каждого блока, таблица помещаемости, список заглушек «уточнити».
