## Критерии приёмки

- [ ] **Видео:** из ролика пользователя взяты 0:00–~6,3 с (до появления надписи ELEADS и дрожащего кольца; точную точку выбрать по кадрам — самолётик над Землёй); 8,3–10 с с выдуманным «сайтом» не используются нигде; звук удалён; перекодировано в `public/video/hero-v3-1080.mp4` (апскейл до 1920×1080, H.264, faststart, ≤ ~4 МБ) и `hero-v3-720.mp4` для мобильного, + постер первого кадра; `muted playsinline`, `preload="auto"` только в варианте 3
- [ ] **Кодовая часть (после видео, ~3–4 с):** космос со звёздами и дугой Земли (продолжение последнего кадра видео, стык — кроссфейд 300–500 мс без скачка), самолётик Telegram (SVG, светящийся, синий как в видео) с оранжевым шлейфом облетает надпись ELEADS по эллипсу, за ним загорается чистое ровное кольцо, самолётик влетает в центр кольца; только `transform`/`opacity` (шлейф — заранее отрисованная дуга, раскрываемая вращением/масштабом слоя, не `stroke-dashoffset`)
- [ ] **Главный экран варианта 3** (кадр 9 раскадровки): «ELEADS» широким капсом, самолётик в горящем кольце, метка «TELEGRAM PERFORMANCE MARKETING», подзаголовок и цифры брифа, CTA «Обговорити проєкт у Telegram →» (`data-place="hero"`), «ГОРТАЙТЕ»; тексты из `content.*.json` (UA/EN); на 1920×1080 — один экран
- [ ] **Интро вместо заставки-поиска в варианте 3:** поиск не показывается; интро — не чаще раза в сутки (тот же `localStorage['eleads-intro']`), `?intro=1` — принудительно; кнопка «Пропустити» и Esc сразу ведут к главному экрану (кроссфейд); при повторном заходе — сразу главный экран; при reduced-motion — сразу главный экран без видео; если видео не загрузилось или не стартовало за 2 с — сразу кодовая часть
- [ ] Переключатель: `?hero=1|2|3`, `sessionStorage['eleads-hero']`, dev-панель «Хиро: 1 / 2 / 3»; неактивные варианты не грузят свои медиа; по умолчанию остаётся вариант 2
- [ ] Hero виден ≤9 с при любой ошибке (правило `intro.js`; для варианта 3 потолок — длина интро + 2 с, задокументировать); 1920×1080 и 360 без горизонтального скролла; `npm run check` зелёный
