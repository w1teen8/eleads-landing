**Требования:** G28, G23, G13
**Зависит от:** 16
**Зона:** `src/data/config.json` · `src/core/sections.js` · `src/main.js` (только включение секций по варианту) · инлайн-скрипт `<head>` / `build/i18n-prerender.js` (если нужно, чтобы `hidden` ставился до отрисовки по варианту) · CSS и JS секций — только правки производительности и стыков · `tests/sections-config.test.js`
**Волна:** 16
**Ревью:** нет

## Что должно заработать

В варианте «Самолётик» (`?hero=3`) под первым экраном идёт вся страница: ленты, Telegram у цифрах, ніші, формати,
калькулятор, кейси, процес, GEO, таргетинг, відгуки, екосистема, матеріали, FAQ, фінальний CTA, подвал — с их
анимациями при прокрутке. В вариантах «Кольцо» и «Синий» страница остаётся только из первого экрана, как просил
пользователь раньше («Остальное все на странице убери»). Прокрутка не лагает.

## Из брифа, дословно

> «Добавь в хиро самолетик продолжение страницы чтобы показать анимацию»

> «Остальное все на странице убери, надо сделать так чтобы не лагало»

## Критерии приёмки

- [ ] `config.json` → `sections`: список включённых секций можно задать по варианту первого экрана (например `byHero: { plane: "all" }`, по умолчанию — `["hero"]`); при `?hero=3` все секции и шапочные якоря видны и инициализированы, при `?hero=2|4` — только первый экран; `hidden` ставится до первой отрисовки (без мигания); тесты обновлены
- [ ] Переход от первого экрана варианта «Самолётик» к лентам — без пустоты и скачка (фон звёздного неба плавно переходит в фон страницы)
- [ ] Производительность прокрутки всей страницы на 1920×1080: замер (puppeteer, плавная прокрутка сверху вниз, CPU без замедления и ×4) — без длинных кадров >50 мс на обычной машине; найденные тяжёлые места облегчены (анимации вне экрана на паузе, без `filter`, только `transform`/`opacity`); числа до/после в возврате
- [ ] Все секции работают как раньше (калькулятор, модалка кейса, лайтбокс, карта, слайдер, FAQ); UA/EN; 1920×1080 и 390 без горизонтального скролла; `npm run check` зелёный
