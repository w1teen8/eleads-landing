## Общие условия (все блоки задачи 3, обновлено 2026-11-10)

- Облик — продолжение блоков 01–05: фон `--bg`, шрифт канала `--font-head` заглавными для H2 и крупных цифр, Onest для текста, карточки — тёмные поверхности `--surface`/`--surface-2` с тонкой `--line` или акцентная жёлто-оранжевая с тёмным текстом; hex только в `tokens.css`; контраст AA. Образцы: блоки 02–05 на живом сайте (http://localhost:5173/) и `reference/run3/*-chosen.png`.
- **Правила клиента (Володимир):** без меток «NN / НАЗВА» над блоками (их уже нет в разметке — не возвращать), без сносок и мелких «нижних надписей» под блоками (`*.footnote`, `*.note`, `*.hint`, `*.caption`, дисклеймеры — убрать из разметки и словарей), без значков у логотипа, без подписей-перечислений клиентов там, где это выглядит как «мои клиенты».
- **Движение:** переходов между экранами нет (H11). Внутри блока разрешены реакции на действие (`flipSwap`, `rollTo` из `stats-odometer.js`) и hover-микродвижения; появление по прокрутке — **не добавлять** (пользователь выбирает его отдельно). Исключение — блоки 11 «Екосистема» и 12 «Матеріали»: там единственный разрешённый переход по прокрутке — лента карточек в духе https://showcase-scroll.framer.ai/ (H07). Только `transform`/`opacity`; reduced-motion и `?nomotion=1` — статично.
- **Формат:** каждый блок — ровно один экран на 1903×937, 1920×1080, 1366×768 (UA и EN), содержимое по центру (правило `.section` в `layout.css` уже даёт `min-height`); 390×844 — без горизонтального скролла. Если содержимого объективно больше одного экрана (кейсы, FAQ) — внутри блока карусель/аккордеон/вкладки, а не длинный список.
- Тексты — только из `content.*.json` / `cases.json` / `faq.json` (ключи с прошлых итераций переиспользовать; новые — в оба словаря); никаких выдуманных фактов, цифр и логотипов: где данных нет — видимая заглушка «уточнити».
- Включение: добавить свой блок в `config.json → sections.enabled` в правильном порядке **точечной правкой** (параллельно работают другие). В `index.html` и словарях — только своя секция, через Edit, перечитывая файл перед правкой.
