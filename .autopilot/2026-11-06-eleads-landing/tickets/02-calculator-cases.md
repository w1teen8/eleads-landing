## Что должно заработать

Посетитель выбирает нишу, GEO и цель пилюлями, тянет ползунок бюджета — и справа в тёмной панели
мгновенно перестраивается воронка «Покази → Кліки → Підписники»: ступени меняют ширину, шесть
показателей диапазонами плавно докручиваются до новых значений. Внизу CPC и CPA/CPS крупно, кнопка
«Отримати точний прогноз →» ведёт в Telegram. Всё проходится с клавиатуры, итог озвучивается
скринридером.

Ниже — семь кейсов карточками, Cryptonite крупнее остальных. Клик по карточке открывает модалку с
полной историей кейса и кнопкой «Написати Володимиру →», без перехода со страницы. Где цифр нет —
честное «уточнити».

## Критерии приёмки

- [ ] `forecast()` — чистая функция без DOM; `tests/calculator-model.test.js` проверяет: при €650, Україна (CPM 2.50), Business (CTR 1.2%), Підписники (CR 35%) медианы — 260 000 показов, 3 120 кликов, 1 092 конверсии, CPC ≈ €0.21, CPA ≈ €0.60; границы = медиана × (1 ∓ 0.15); CPC и CPA считаются от противоположных концов
- [ ] При нуле, отрицательном или нечисловом коэффициенте `forecast` возвращает `null` по затронутым показателям, а UI показывает «—», без `NaN` и `Infinity`
- [ ] `calculator.json`: `demo: true`, `spread: 0.15`, `cpm` по 2 GEO, `ctr` по 4 нишам, `cr` по 2 целям, `budget: {min: 650, max: 10000, default: 1500}`; ниш, GEO и целей в коде нет — только в JSON
- [ ] При `demo: true` над прогнозом видна плашка «демо-коефіцієнти»
- [ ] Ниша / GEO / цель — радиогруппы: стрелки переключают, Tab переходит между группами; выбранная пилюля — фирменный градиент, не синий
- [ ] Слайдер — `input[type=range]` от €650 до €10 000 с нелинейной шкалой (шаг €50 до €2 000, €250 выше); на максимуме подпись «€10 000+»; `aria-valuetext` с суммой в евро
- [ ] Любое изменение пересчитывает всё в том же кадре, числа докручиваются ~350 мс; три ступени воронки меняют ширину через `transform: scaleX`, нижняя не уже 14%
- [ ] При цели «Користувачі бота» третья ступень называется «Користувачі»
- [ ] Шесть показателей — диапазонами; CPC и CPA/CPS крупно моноширинным
- [ ] Результат в `aria-live="polite"`, обновление одной фразой через 500 мс после остановки
- [ ] Дисклеймер, CTA «Отримати точний прогноз →» и строка «Не знайшли свою нішу?…» — дословно; обе ссылки ведут в Telegram
- [ ] `calculator_change` с `niche, geo, goal, budget` уходит в `dataLayer` с дебаунсом 600 мс; клик CTA даёт `calculator_cta_click` и `cta_telegram_click` с `place: calculator`
- [ ] Раскладка: «Параметри кампанії» слева, тёмная «Орієнтовний прогноз» справа; на мобильном — друг под другом, без горизонтального скролла на 360px
- [ ] `cases.json` содержит 7 кейсов брифа в его порядке; каждый — `niche`, `name`, `budget`, `result`, `cpa`, `task`, `geo`, `done[]`, `review`; неизвестное — «уточнити»; тексты на двух языках внутри записи
- [ ] Сетка кейсов: Cryptonite занимает больше места, остальные — не одинаковые клоны; цифра CPA/CPS — самый крупный элемент карточки
- [ ] Клик или Enter/Space по карточке открывает модалку со всеми полями брифа и кнопкой «Написати Володимиру →»; закрытие по Esc, клику вне и кнопке; фокус заперт внутри и возвращается на карточку; фон не скроллится (Lenis на паузе)
- [ ] Открытие модалки даёт `case_open` с названием кейса; кнопка в модалке — `cta_telegram_click` с `place: case_modal`
- [ ] Переключение языка перерисовывает калькулятор и кейсы, сохраняя выбранные значения и бюджет
- [ ] Ключи разделов `calculator` и `cases` совпадают в UA и EN; `npm run check` зелёный
