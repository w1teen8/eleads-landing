## Общие условия (для всех блоков задачи 3)

- Облик — продолжение синего первого экрана (как блок 02 из таска 19): синий фон, белые карточки, синие акценты, тёмно-синяя `#070C18` акцентная карточка; жёлто-оранжевый — только мелкие акценты; контраст AA.
- Движение — **только** из общего набора `src/core/motion-kit.js` (таск 19): блок входит **главой** (`stackReveal`) поверх предыдущего; всё меняющееся — **табло** (`flipSwap`); появление — **лесенка** (`stagger`). Свои новые эффекты не вводить — правило пользователя «чтобы они были в одну тему друг с другом» (H10). Локальные hover-микродвижения допустимы.
- Тексты — из `content.*.json` (UA/EN), ключи блока уже есть с прошлых итераций — переиспользовать; никаких выдуманных фактов.
- Разметка — только внутри своей `<section>` в `index.html` (точечными правками: параллельно работают другие блоки); `config.json → sections.enabled` — добавить свой блок в правильном порядке точечной правкой.
- 1920×1080 главный, 1366×768 и 390×844 — без горизонтального скролла; только `transform`/`opacity`; reduced-motion — статично и всё видно.
- `npm run check` и `MSYS_NO_PATHCONV=1 BASE_PATH=/eleads-landing/ npm run check` — зелёные (падение только в чужом блоке, который ещё пишется, — не твоё, отметь).
- В возврате — скриншот блока 1920×1080 и 390×844 и контактный лист ~10 кадров входа блока.
