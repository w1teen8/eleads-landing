## Что должно заработать

«Таргетинг», «Відгуки + засновник» и «Матеріали» выглядят как bento-портфолио neu-bento, но в тёмной палитре
бренда: плитки разного размера в одной сетке, чипы-теги, пилюли-кнопки `↗`, круглые кнопки. Блок основателя с
отзывами — один экран плиток. Обложки постов, фото основателя и телефоны с рекламой при прокрутке входят
наклонёнными и выпрямляются, как в portfolea. Скорость перемерена после всей сборки 2, и честно записано,
что с ней стало.

## Критерии приёмки

- [ ] «Таргетинг»: bento — 6 плиток разного размера в одной сетке с одинаковым зазором, чип-тег в углу, пояснение раскрывается как раньше (hover и фокус)
- [ ] «Відгуки + засновник» — один bento-блок: большая плитка с фото, плитка с текстом «Привіт, я Володимир…», плитка цифр 7+ / $2M+ / десятки, плитка отзыва с цитатой и двумя круглыми стрелками (слайдер внутри плитки, свайп на мобильном, клавиатура), плитка Telegram с круглой кнопкой → `t.me/Kucherflow`, `data-place="founder"`. Тексты не изменены
- [ ] «Матеріали»: 4 обложки — плитки разного размера + пилюля «Читати в Telegram ↗»
- [ ] Палитра тёмная, никаких светлых неоморфных теней; радиусы различаются по роли; на 360px — одна колонка без горизонтального скролла
- [ ] `tiltOnScroll` вызван на обложках «Матеріалів», фото основателя и телефонах «Як виглядає реклама»; на reduced-motion — ровно
- [ ] Lighthouse mobile перепрогнан на `npm run build && npm run preview` (3 прогона, медиана); в `docs/qa-report.md` раздел «После сборки 2» — числа, LCP и причина: 5-секундная заставка по слову пользователя
- [ ] Ключи UA/EN совпадают; `npm run check` зелёный
