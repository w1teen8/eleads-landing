## Анимации — fintap.framer.website (G01)

Добавлено 2026-11-06: «Анимации как тут сделай».

Исходники страницы прочитать не удалось: фетчер вернул только текст, без inline-стилей, скриптов и значений easing. Поэтому язык движения зафиксирован как характеристика жанра Framer-шаблонов такого типа, и его подтверждает пользователь на брифинге:

| Приём | Как делаем у нас |
|---|---|
| Появление блоков по скроллу | `opacity` 0→1 + `translateY` 24–40px, стагер 60–90 мс по дочерним элементам, один раз (`once: true`) |
| Пружинность | GSAP `power3.out` / `power4.out`, 0.6–0.9 с — визуально близко к Framer spring, но дешевле blur-эффектов |
| Залипающие секции | ScrollTrigger `pin` на 1–2 ключевых блоках (калькулятор или процесс), остальное — обычные ревилы |
| Мягкий параллакс | фоновые слои `translate3d` с коэффициентом 0.05–0.15 от скролла |
| Бегущая строка | бесконечный `translateX`, пауза при наведении (R46) |
| Счётчики | докрутка цифр при входе в экран (R43, R47, R60) |
| Hover-микродвижения | `scale(1.02)` / сдвиг стрелки в кнопке, 150–200 мс |
| Инерционный скролл | Lenis (R10) |

Ограничения брифа сильнее референса: только `transform` и `opacity` (R24), никакого анимированного blur и filter, `backdrop-filter` только в шапке (R25), всё выключается при `prefers-reduced-motion` (R28).

**shining-three-588967.framer.app (Outrank) — загрузка (G03) и переходы (G04)**
- Загрузка ~5 с: тёмный экран; логотип слева вверху, кнопка `SKIP →` справа вверху; по центру белая строка поиска (иконка лупы, кнопка-стрелка справа) с мигающим курсором; слева внизу `● SEARCHING`, справа внизу подпись `LOADING` и огромный трёхзначный счётчик `000`.
  0,8–2,4 с курсор мигает в пустой строке → 2,8–3,6 с запрос набирается по буквам (счётчик 033→054) → 4,0 с кнопка поиска загорается акцентом, под строкой три «скелетона» результатов с бегущим бликом (071) → 4,4–4,8 с первый результат проявляется как карточка их сайта и подсвечивается (091→095) → 5,2 с `100`, из правого верхнего угла идёт скошенная акцентная полоса и открывает сайт.
  У них уход шторки сделан анимацией `clip-path` — **у нас запрещено (R24)**: тот же вид делается скошенной полосой на `transform`.
- Переход между страницами (`.ortr`): во весь экран проезжает полоса акцентного цвета `skewX(-10deg)` (`translateX(-106%) → 0`, `cubic-bezier(.7,0,.25,1)`), на ней «едет» плашка: мелко домен, крупно пилюля с логотипом, названием страницы и бейджем `#1`, который выпрыгивает (`scale(.3) rotate(-14deg) → 1`, `cubic-bezier(.34,1.7,.6,1)`); затем полоса уезжает дальше и открывает новую страницу.
- Заголовки: вторая строка лежит на акцентной плашке-маркере («page one.», «on page one.»).
- Hero: чёрно-белое фото, по нему за курсором ходит круглая «линза» с жёлтой обводкой, внутри которой фото цветное.
- Закреплённые секции с номерами `01 / … 06 /`: слева текст стоит, справа меняются карточки; огромные полупрозрачные номера отсчитываются при прокрутке (`#50 → #22 → #8 → #1`).
- Подвал: огромный логотип-вордмарк на всю ширину на акцентной плашке.
