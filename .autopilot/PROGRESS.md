## Договорились — не пересматривать

- Калькулятор — воронка «Покази → Кліки → Підписники» + табло CPC/CPA: «калькулятор сделай как знаешь» (R63)
- Английский переводим сами, черновик с `"draft": true`: «англ страницу сам переведи» (R100i)
- Анимации — язык движения fintap.framer.website в рамках правил брифа (только transform/opacity): «Анимации как тут сделай» (G01)
- Меток «NN / НАЗВА» над блоками нет, сносок под блоками нет, у логотипа eLeads нет значка — Володимир: «Нижние надписи в блоках не нужны … номер блоков тоже не надо и их название … возле eLeads не надо знак телеграм вообще никакой» (2026-11-09)
- В палитре 9 цветов брифа + `--grad` — ADR 0006
- Репозиторий на GitHub публичный, сайт на GitHub Pages: «Короче кидаем его на гитхаб в публичный репозиторий» (2026-11-09; ADR 0005 устарел)
- Каждое законченное зелёное изменение выкладывается на GitHub без напоминаний, для живого просмотра — dev-сервер на :5173: «Каждое изменение закидывай на гитхаб, или давай ты просто локалку мне откроешь»

- Оформление и анимации: варианты предлагаются, выбирает пользователь; свой вариант в работу не отправлять — «предложи, а я выберу, ты не делаешь как хочешь» (2026-11-09)

- Калькулятор без плашки «демо-коефіцієнти» и без подписей «бота» — «это сайт, а не сообщение бота» (2026-11-10)

## Известные баги

- Ответ FAQ «Скільки коштують послуги?» — «індивідуально», ответы 3, 4, 5, 8 собраны из текстов страницы — клиенту подтвердить
- Пре-рендер молча пропускает `[data-i18n]` с вложенными тегами — сейчас таких нет
- `lockScroll` — флаг, не счётчик: лайтбокс внутри модалки разблокировал бы страницу
- Мёртвый код: `pinSection` в `src/core/motion.js`
- Прелоадер, упавший на шаге ухода (~2,6 с): hero виден сразу, шторка уходит ещё до 1,3 с
- При reduced-motion якоря прокручивают через `scrollToTarget` → `window.scrollTo`, который не учитывает `scroll-margin-top` (под шапку уходит ~60px) — правка в `src/core/motion.js` (T23)
- Мёртвый код: `initTrusted()` в `src/sections/hero.js` — полосы «Мені довіряють» больше нет, её заменили ленты (T23)
- Карты блока 02 — SVG: на машине вдвое медленнее обычной при движении курсора ~51 fps; если заметно — перевести точки на canvas (T25)
- Анимации блока 02 не проверены в Safari и Firefox (T25)
- `docs/qa-report.md` упоминает «4,500»; в `AGENTS.md` число тестов (61) устарело
- Не проверено: реальный Android, Safari, Firefox, живой тап по карте, страница с упавшим GSAP
