# Промпт для Claude Code: лендинг eLeads

Скопируй всё ниже в Claude Code. Скрины вайрфрейма (15 шт.) и обложку поста из канала положи в папку `/reference` проекта до запуска.

---

## Роль и задача

Ты senior frontend-разработчик и motion-дизайнер. Делаем одностраничный лендинг эксперта по Telegram Ads — Володимира Кучера (бренд eLeads, Telegram @Kucherflow). Сайт должен давать «вау» с первого экрана, выглядеть как дорогой кастомный проект, а не шаблон, и при этом летать на среднем Android.

Сейчас этап **МАКЕТА**: делаем шапку, hero, калькулятор и кейсы в полном качестве, остальные блоки каркасом с реальным контентом. После согласования с клиентом доделываем всё остальное.

Перед кодом:
1. Изучи все файлы в `/reference`: это вайрфрейм клиента (структура) и обложка поста (бренд).
2. Напиши короткий план: структура файлов, библиотеки, как устроен каждый блок, где будет «вау».
3. Дождись моего «ок» и только потом пиши код.

## Стек

- Vite + vanilla JS (без React), чистый HTML/CSS.
- GSAP + ScrollTrigger для анимаций, Lenis для плавного скролла.
- Весь контент вынести в JSON в `/src/data`: `content.ua.json`, `content.en.json`, `cases.json`, `faq.json`, `calculator.json`. Клиент и я должны менять тексты и цифры без правки вёрстки.
- Сборка в статику (`dist/`), деплой на обычный хостинг клиента.
- Никаких тяжёлых UI-фреймворков и Tailwind-шаблонности.

## Производительность (обязательно)

- Анимировать только `transform` и `opacity`. Не анимировать blur, filter, box-shadow, размеры.
- `backdrop-filter` только в шапке.
- Не больше одного canvas/WebGL на странице, ставить его на паузу вне экрана.
- Изображения в WebP/AVIF, lazy-load всё ниже первого экрана.
- Поддержать `prefers-reduced-motion`: эффекты выключаются, контент виден.
- Контент виден без JS-анимаций: ничего не прячем через `opacity: 0` навсегда.
- Цель: Lighthouse на мобильном 85+ по Performance, 0 горизонтального скролла на 360px.

- Прелоадер 1–1,5 сек: проценты огромным condensed-шрифтом в градиенте, потом шторка уходит вверх.
- Надзаголовок: TELEGRAM PERFORMANCE MARKETING.
- Заголовок «ПРОСУВАННЯ ЧЕРЕЗ TELEGRAM ADS»: выезжает по строкам из маски, «TELEGRAM ADS» в градиенте.

### 06–07 Кейси
Карточки: Cryptonite, Finmap, Global Auto Logistic, Князєв (Auto / Korea), Олександр Мухін, Віктор Домбовецький, Trackdesk. На карточке ниша-тег, название, бюджет, результат, CPA/CPS крупными цифрами. Один кейс крупнее остальных.

## Языки

## Аналитика
Все клики по Telegram и взаимодействия с калькулятором отправлять в `window.dataLayer` событиями: `cta_telegram_click` (с местом клика), `calculator_change` (ниша, GEO, цель, бюджет), `calculator_cta_click`, `case_open` (название кейса). GA4 и Meta Pixel подключатся через ID в конфиге, пока пустые.

## SEO и мета
Title, description, Open Graph-картинка, favicon, семантичные заголовки, alt у картинок, `lang`.
