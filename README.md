# eLeads — лендинг Володимира Кучера (Telegram Ads)

Односторінковий сайт: Vite + vanilla JS, GSAP, Lenis. Весь текст лежит в JSON. Две языковые версии: украинская (по умолчанию, вшита в HTML при сборке) и английская (черновик, подставляется в браузере).

## Установка и запуск

Нужен Node 20+ (проверено на Node 24, npm 11).

| Команда | Что делает |
|---|---|
| `npm install` | поставить зависимости |
| `npm run dev` | локальный сервер с горячей перезагрузкой |
| `npm run build` | собрать статику в `dist/` |
| `npm run preview` | посмотреть собранный `dist/` локально |
| `npm run check` | тесты (`node --test`) и сборка — должна быть зелёной перед каждой выкладкой |

Один файл тестов: `node --test tests/<файл>.test.js`.
Проверка без анимаций: открыть сайт с `?nomotion=1` (то же, что `prefers-reduced-motion`).

Результат проверки скорости, экранов и клавиатуры — в `docs/qa-report.md`.

## Куда положить материалы клиента

Всё, что клиент присылает, кладётся в `public/` — Vite копирует это в `dist/` как есть.

| Что | Куда | Файлы |
|---|---|---|
| Видео первого экрана | `public/video/` | `hero-1080.mp4` (десктоп), `hero-720.mp4` (мобильный), `poster.jpg` (кадр-заставка). Сейчас стоит абстрактная петля 12 с в цветах бренда; чтобы заменить — положите свои файлы с теми же именами. |
| Фото Володимира | `public/img/photo/` | Подключены три кадра: `volodymyr-hero-*`, `volodymyr-founder-*`, `volodymyr-cta-*` — каждый в AVIF, WebP и JPG двух ширин. Чтобы заменить, положите файлы с теми же именами и размерами. Исходники фотосессии в репозиторий не входят. |
| Логотипы клиентов | `public/img/logos/` | 7 файлов SVG/PNG. |
| Скриншоты рекламы | `public/img/ads/` | 3 файла: канал, медиа, бот. |
| Аватары клиентов в кейсах | `public/img/cases/` | Квадратные WebP: `<id>.webp` (256×256) и `<id>@2x.webp` (512×512), где `<id>` — `id` кейса в `src/data/cases.json`. Подключены: `cryptonite`, `monolit`, `global-auto-logistic`, `trackdesk`, `mukhin` (аватар ПроSales), `dombovetskyi`, `finmap`, `kniaziev` (у `kniaziev` исходник 160×160 — файл один, без `@2x`; в данных `"avatarRetina": false`). Картинка запрашивается только у кейса с `"avatar": true`; `"accent": "#hex"` там же — цвет бренда для акцентов карточки. Без аватара — круг с первой буквой имени. |
| Скриншоты кейсов | `public/img/cases/<id>.webp` | путь указывается в `src/data/cases.json`, поле `screenshot` |
| OG-картинка, favicon | `public/og.jpg` (1200x630), `public/favicon.svg` | сейчас заглушки |

Важно: **подключены видео первого экрана, фото Володимира и скриншоты кейсов**. Логотипы и скриншоты реклам в разметке сейчас показаны названиями и макетами — после получения файлов нужна небольшая правка `index.html` (место помечено меткой-заглушкой на самом сайте).

## Як змінювати тексти

Усі тексти сайту (українською й англійською, FAQ, кейси, підписи калькулятора, посилання й нік Telegram) можна змінити
в браузері на сторінці **https://w1teen8.github.io/eleads-landing/admin/** — без коду. На сайті посилання на неї немає,
пошуковики її не індексують.

**1. Створіть токен GitHub (один раз).**

1. Відкрийте https://github.com/settings/personal-access-tokens/new (потрібен вхід у GitHub-акаунт, що має доступ до репозиторію).
2. **Token name** — наприклад, «eLeads тексти». **Expiration** — скільки токен житиме (наприклад, 90 днів; потім створіть новий).
3. **Repository access** → **Only select repositories** → виберіть `w1teen8/eleads-landing`.
4. **Permissions** → **Repository permissions** → **Contents** → **Read and write**. Більше нічого не вмикайте.
5. **Generate token** і скопіюйте його (починається з `github_pat_`). GitHub покаже його лише раз.

**2. Увійдіть.** Відкрийте `/admin/`, вставте токен, натисніть «Увійти». Токен зберігається тільки у вашому браузері
(до закриття вкладки; з галочкою «Запамʼятати на цьому пристрої» — довше) і надсилається лише на `api.github.com`.
Кнопка «Вийти» стирає його. На чужому компʼютері галочку не ставте.

**3. Змініть тексти.** Зліва — розділи в порядку сторінки, справа — поля: UA і EN поруч. Пошук шукає по всіх текстах.
Змінені поля підсвічені, вгорі лічильник «Змінено: N»; «Повернути» скасовує одне поле, «Скасувати зміни» — усі.
Порожнім поле залишити не можна, переносів рядка й понад 2000 символів — теж.

**4. Збережіть.** «Зберегти» записує всі зміни одним комітом у гілку `main`. Сайт оновиться сам за 2–3 хвилини —
хід видно за посиланням «Хід публікації (GitHub Actions)». Якщо, поки ви редагували, тексти на GitHub хтось змінив,
адмінка нічого не перезапише й запропонує «Оновити й повторити»: ваші правки ляжуть поверх нової версії.

Якщо токен загубили або він міг потрапити до чужих рук — видаліть його на https://github.com/settings/personal-access-tokens
і створіть новий.

Для розробника: сторінка — `admin/index.html` (друга точка входу Vite, `dist/admin/index.html`), код — `src/admin/`
(`config.js` — власник, репозиторій, гілка; `fields.js` — JSON → поля; `json-text.js` — правка значень без зміни
форматування файлу; `github.js` — читання й коміт через Git Data API). Тести — `tests/admin-*.test.js`.

## Где править тексты и данные

Всё в `src/data/`:

| Файл | Что в нём |
|---|---|
| `content.ua.json` | украинские тексты всех секций (ключи вида `hero.title`) |
| `content.en.json` | английские тексты; набор ключей должен совпадать с украинским (проверяет тест). Пока черновик: `"draft": true` в корне — когда текст вычитан, строку убрать |
| `cases.json` | 7 кейсов: ниша, название, бюджет, результат, CPA, отзыв, список «что сделано»; значения «уточнити» / «TBD» — заглушки |
| `faq.json` | вопросы и ответы (по языкам) |
| `calculator.json` | коэффициенты калькулятора прогноза |
| `config.json` | ссылка и ник Telegram, ID аналитики (`ga4Id`, `metaPixelId` — пустые, пока не заданы, аналитика не подключается) |
| `geo-dots.json` | сетка точек карты мира и регионы |
| `ua-dots.json` | Украина в виде сетки точек для блока 02 «Telegram у цифрах»; собирается скриптом `scripts/ua-dots.js`, руками не правится |

В `index.html` нет текстов — только разметка с атрибутами `data-i18n="раздел.ключ"`. Новый текст = новый ключ в **обоих** `content.*.json`. Отсутствующий ключ роняет `npm run build` с перечнем.

### Карта Украины из точек

`src/data/ua-dots.json` — контур Украины в международно признанных границах (с Крымом, Донецкой и Луганской областями), переведённый в шахматную сетку точек. Сколько точек горит, задаёт цифра `stats.ua.main.value` в `content.*.json` («81%» — горит 81% точек).

Источник контура: Natural Earth, Admin 0 – Countries, вариант «точка зрения Украины» (`ne_10m_admin_0_countries_ukr`, 1:10m), https://www.naturalearthdata.com/. Лицензия: общественное достояние (public domain). В обычном варианте Natural Earth Крым отнесён не к Украине — его брать нельзя.

Пересобрать сетку (сам GeoJSON в репозиторий не кладётся):

```
curl -L -o ne_ukr.geojson https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_0_countries_ukr.geojson
node scripts/ua-dots.js ne_ukr.geojson
```

Скрипт сам проверяет, что Симферополь, Донецк, Луганск, Львов и Киев лежат внутри контура и попали в сетку; то же проверяет `tests/stats-map.test.js`.

### Коэффициенты калькулятора

Калькулятор считает по формулам из `src/sections/calculator-model.js`:
показы = бюджет / CPM x 1000; клики = показы x CTR; подписчики или пользователи бота = клики x конверсия; CPC и CPA — из них. Диапазон — медиана ± `spread` (0.15).

Числа — в `src/data/calculator.json`: `cpm` (по географии), `ctr` (по нишам), `cr` (конверсия: `subscribers`, `bot_users`), `budget` (границы и шаг ползунка).
Клиент заполняет форму **`client-data/calculator-template.csv`** (ниша; гео; цель; CPM в евро; CTR %; конверсия %; комментарий) — по ней значения переносятся в `calculator.json`. Пока файл не заполнен, там демо-значения и `"demo": true` — на сайте это показано дисклеймером; при замене на настоящие числа поставить `"demo": false`.

## Как выложить на хостинг

1. `npm install` и `npm run check` (должно быть зелёным).
2. `npm run build` — готовый сайт в папке `dist/`.
3. Загрузить **содержимое** `dist/` (не саму папку) в корень сайта на обычном хостинге: по FTP / SFTP или через файловый менеджер панели хостинга. Серверной части нет, PHP и Node не нужны.
4. Проверить в браузере: главная открывается, переключатель UA/EN работает, видео (если уже загружено) играет.

Замечания:
- Сайт рассчитан на раздачу из корня домена (пути вида `/assets/...`). Для подпапки нужен `base` в `vite.config.js`.
- В `dist/` попадает `robots.txt` (разрешить всё). Свой положить в `public/robots.txt` — тогда используется он; адрес `Sitemap:` добавить, когда будет известен домен.
- Если на хостинге включено сжатие gzip/brotli и кэш для `/assets/` — скорость будет выше, чем на `npm run preview`.
- OG-картинка подключена относительным путём `/og.jpg`; для превью в соцсетях добавить абсолютный `og:url` и адрес картинки, когда будет известен домен.

## Структура

```
index.html            разметка всех 14 секций (без текстов)
admin/index.html      админка текстов /admin/ (код — src/admin/)
build/                плагин сборки: вшивает украинский текст и пишет robots.txt
scripts/ua-dots.js    сборка src/data/ua-dots.json из открытого контура Украины
src/main.js           точка входа: язык, секции, анимации, аналитика
src/core/             язык, DOM-помощники, форматы чисел, анимации (GSAP/Lenis), аналитика
src/sections/         по модулю на секцию (подхватываются по data-section)
src/styles/           tokens.css, base.css, layout.css, sections/*.css
src/data/             все тексты и числа (JSON)
public/               материалы клиента
tests/                node --test
docs/qa-report.md     отчёт о проверке и список «что не дотянуто»
```

Правила проекта: анимируются только `transform` и `opacity`; `backdrop-filter` — только в шапке; на странице один `<canvas>` (карта); без JS и при «уменьшить движение» весь контент виден.
