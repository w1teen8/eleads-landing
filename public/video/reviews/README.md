# Відеовідгуки клієнтів

Сюди кладуться відеовідгуки для блоку «Що говорять підприємці» — великий круг зліва, як відеокружок у Telegram.
Поки файлів немає: у крузі аватар клієнта й підпис «відео-відгук скоро».

## Як додати відеовідгук

1. Файл — квадратне відео (наприклад, 720×720), MP4 (H.264), до ~1 хвилини й ~10 МБ; назва латиницею без пробілів:
   `mukhin.mp4` (Олександр Мухін), `dombovetskyi.mp4` (Віктор Домбовецький).
2. Покладіть файл у цю папку (на GitHub: **Add file → Upload files** → **Commit changes**). Замінити — завантажте файл
   з тією самою назвою.
3. В адмінці `/admin/` → розділ «Відгуки» → поле «№1 · Файл відео» (або №2) впишіть `video/reviews/mukhin.mp4` —
   у UA і EN — і натисніть «Зберегти». Поле в словниках — `reviews.items.<N>.video` (`src/data/content.ua.json`,
   `content.en.json`).
4. Прибрати відео — очистіть поле й збережіть.
